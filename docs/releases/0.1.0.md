# reverse-jailbreak 0.1.0

This is the first independently installable release of the model campaign tool.

## Included

- Five campaign algorithms: builtin, PAIR, TAP, Crescendo, and Evolution.
- Five packaged instruction profiles that work outside the source checkout.
- OpenAI-compatible endpoint readiness checks and bounded transport controls.
- Plan, validation, execution, stable checkpoint, resume, report, and promotion
  lifecycle commands.
- Heuristic and independent-model semantic judging with traceable verdicts.
- Artifact redaction, hashing, provenance, and release manifest verification.

## Acceptance

The package workflow builds the wheel, verifies the portable manifest, installs
the wheel in a fresh virtual environment, and exercises the installed CLI. The
live endpoint workflow is opt-in through GitHub `workflow_dispatch`; it executes
doctor, run, checkpoint, cross-session resume, report, and promote, then retains
the sanitized evidence as a workflow artifact.

## Upgrade Notes

API credentials are referenced by environment-variable name. Campaign files and
release artifacts must not contain credential values or Authorization headers.

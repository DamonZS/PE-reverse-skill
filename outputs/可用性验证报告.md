## 三、必须记住的运行前提（避免再次踩坑）

| 前提 | 说明 |
|------|------|
| **永远用 `.venv` 的 python** | `D:\Project\PE-reverse-skill\.venv\Scripts\python.exe`，不要用全局 `python`（它缺依赖） |
| **Go 平台要指向 `.venv`** | 启动 server 时设置 `REVERSE_ANALYZER_PYTHON=.venv\Scripts\python.exe`，否则它会去找系统 `python` |
| **本地无需 PostgreSQL** | 默认 `REVERSE_ANALYZER_ENV=local-dev`，用 `storage:json` 降级，只有 `Production=true` 才强制 DB |
| **默认地址** | `127.0.0.1:8090`（`REVERSE_ANALYZER_WEB_ADDR`） |
| **可选重型依赖** | `frida/comtypes/opencv/apktool/jadx` 等标记 `unavailable` 属正常，项目有降级逻辑，不影响核心 |

# Intelligent Reverse Router Implementation Summary

## Finding

The suite now starts from one master skill and returns a deterministic workflow
plan for PE files, URL/interface descriptors, package ecosystems, and
protection-review requests.

## Evidence

See `../evidence/E-001.md` for the exact verifier and test commands.

## Boundary

The router only classifies and indexes local workflows. License, anti-tamper,
anti-cheat, and EDR routes are controlled evidence-review plans; they do not
automate bypass, patching, injection, disablement, or evasion.
